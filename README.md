# Dreamland
**A 3D procedural world generator using Rust, Bevy, WASM, and WebGPU.**

Dreamland is an infinite world that continuously generates around the user, rendering in high quality close by and tapering off when far away. This project is designed firstly to be a personal foray into the subject, and perhaps alternatively as a flexible visualization of terrain generators for game developers, 3D artists, and others. This experience is designed to be accessible on the web, enabling greater accessibility.

## Roadmap

- Physics Engine Integration

- Rendering Optimizations
- Procedural Atmosphere
- GPU Compute Noise Generation

### In Progress

- Infinite Generation

### Planned
